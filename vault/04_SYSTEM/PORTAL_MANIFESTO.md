The board tracks work across five columns:

- **RAW** — New ideas, unfiltered
- **REFINED** — Clarified, scoped
- **PLANNED** — Ready to execute
- **IN PROGRESS** — Someone is actively working on it
- **DONE** — Completed with a completion note

You can interact with the board through the MUD client (`add`, `working on`, `done`) or by reading the synced markdown file in `03_SHARED/OPERATIONAL_BOARD.md`.
