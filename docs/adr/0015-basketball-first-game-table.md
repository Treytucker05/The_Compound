# Make Basketball Shootout the first Lobby Game Table

**Status:** Accepted - 2026-08-19

The Lobby needs one real, enjoyable activity to prove the social layer rather than a collection of unbuilt game ideas. Trey chose Basketball Shootout as that first shared experience.

## Decision

- Basketball Shootout is the first Game Table selected for design and implementation.
- It is a lightweight, native two-Member Lobby game and follows the Game Table boundary.
- Pool, air hockey, and soccer remain future Game Table candidates rather than requirements for the first release.
- Basketball Shootout's multiplayer mechanics, scoring, and presentation require their own follow-up decision.

## Consequences

- The social-game implementation can be validated with one focused experience.
- The first game can establish reusable Lobby multiplayer patterns.
- Other games do not delay the initial Lobby release.
