# Use a 2D Clubhouse as the Lobby

**Status:** Accepted - 2026-08-19

The Compound needs a shared place that feels social rather than a work dashboard, but a full 3D avatar world would add performance and navigation complexity that does not help Trey and Joe collaborate or casually play games.

## Decision

- The Lobby is an interactive two-dimensional Clubhouse, not a panel-only dashboard and not a three-dimensional virtual world.
- Each Member has a clear, labelled visual presence anchor in the Clubhouse.
- Radio status, text chat, and available Game Tables are visible parts of the shared room rather than hidden utility screens.
- Members can enter their Workstations through direct, clear controls; moving an avatar around the room is never required to work.
- The Clubhouse visual language should use real status and activity, a restrained palette, and purposeful room objects rather than generic dashboard cards or decorative effects.

## Consequences

- The Lobby can feel personal and social while staying light enough for the Windows Desktop coordination host.
- Game Tables have a natural shared location without competing with project work surfaces.
- Detailed illustration, layout, and motion treatments remain design work to validate against the real rendered interface.
