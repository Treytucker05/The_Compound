# Put initial shared games at Lobby game tables

**Status:** Accepted - 2026-08-19

The Compound needs low-pressure shared activities for when Trey and Joe are not working. Using Projector Windows for those activities would add streaming cost and blur the line between a social game and a shared work application.

## Decision

- Initial games are native, lightweight multiplayer Game Tables in the Lobby.
- A Game Table is opened intentionally by Members who want to play together; it does not require an Execution Host, Connector share, or Projector Window.
- A Game Table cannot access project files, LLM sessions, host applications, or computer-control capability.
- Basketball, soccer, air hockey, and pool are candidate Lobby Game Tables; their order and exact rules remain separate product decisions.

## Consequences

- Social play stays visually and conceptually in the Lobby.
- Games do not consume the shared high-bandwidth projection budget.
- Each game can have its own simple multiplayer interaction model without changing Workstation or Projector behavior.
